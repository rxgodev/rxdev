# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in RXDev, please report it by opening a draft security advisory at:

https://github.com/rxgodev/rxdev/security/advisories

Do **not** open a public issue for security vulnerabilities.

## What to Include

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix (if known)

## Response

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

RXDev handles API keys and executes git commands. Vulnerabilities related to:
- Exposure of API keys or tokens
- Command injection via git operations
- Unauthorized file system access

...are considered high priority.
