Авто-коммит — мощный CLI-инструмент для генерации комментариев для коммитов на базе ИИ. Это позволяет тебе не думать об изменениях в коде или учить правила написания комментариев, а просто наслаждаться.

> [!WARNING]
> **Уведомление об использовании токенов**: Мы используем бесплатное решение от [io.net](https://io.net). Все токены тратятся в их API. Лимиты обновляются ежедневно.

## Установка

#### Вход в pnpm
1. Получите PAT-ключ от аккаунта по [ссылке](https://github.com/settings/tokens) с правом `write:packages`

```bash
# 2. Войдите в pnpm
pnpm login --scope=@rxgodev --registry=https://npm.pkg.github.com/
```

3. Введите свой юзернейм и токен (в поле "Пароль")

#### Установка из pnpm

```bash
pnpm add -g @rxgodev/ac@latest
```

Авто-коммит успешно установлен 🎉

## Настройка

#### После [установки](#installation), получите API-ключ по [ссылке](https://ai.io.net/ai/api-keys). Затем используйте следующую команду и введите ключ

```bash
qq config
```

#### Вы можете настроить файлы, которые не будут описываться ИИ

Измените `.commitignore`, как `.gitignore`. По умолчанию, туда встроены файлы, связанные с `.githooks`.

## Быстрый Старт

> [!NOTE]
> Код использует 6 ИИ-моделей, каждая из них использует по 500.000 токенов. Это позволяет сделать до ~6000 коммитов в день.

```bash
# Инициализация git-хуков в директории проекта
qq init

# Получите API-ключ с https://ai.io.net/ai/api-keys и введите в соответствующее поле
# Затем используйте это:
git add .
git commit

# Прочитайте комментарий, при необходимости, добавьте или измените свои пункты
:wq # Команда для Сохранения и Выхода из файла
git push
```

## Обновление

#### Установка последней версии из pnpm

```bash
pnpm add -g @rxgodev/ac@latest
```

#### Инициализируйте директорию ещё раз

```bash
qq init
```

Обновление успешно установлено 🎉
