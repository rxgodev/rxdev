NeuroCommit — мощный CLI-инструмент для генерации комментариев для коммитов на базе ИИ. Это позволяет тебе не думать об изменениях в коде или учить правила написания комментариев, а просто наслаждаться.

> [!NOTE]
> Сообщения коммитов генерируются через бесплатный эндпоинт [apifreellm.com](https://apifreellm.com). Не нужен ни API-ключ, ни регистрация, ни квоты на токены.

## Установка

#### Вход в pnpm
1. Получите PAT-ключ от аккаунта по [ссылке](https://github.com/settings/tokens) с правом `write:packages`

```bash
# 2. Войдите в pnpm
pnpm login --scope=@rxgodev --registry=https://npm.pkg.github.com/
```

3. Введите свой юзернейм и токен (в поле "Пароль")

#### Установка из pnpm

```bash
pnpm add -g @rxgodev/neuro-commit@latest
```

NeuroCommit успешно установлен 🎉

## Настройка

#### Опциональные настройки (подпись co-author, список проектов, шаблоны)

```bash
qq config
```

#### Вы можете настроить файлы, которые не будут описываться ИИ

Измените `.commitignore`, как `.gitignore`. По умолчанию, туда встроены файлы, связанные с `.githooks`.

## Быстрый Старт

```bash
# Инициализация git-хуков в директории проекта
qq init

# Ключ не нужен — просто коммитьте:
git add .
git commit

# Прочитайте комментарий, при необходимости, добавьте или измените свои пункты
:wq # Команда для Сохранения и Выхода из файла
git push
```
